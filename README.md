# 오늘의 교수님은 뭘까용~? (Who's That Professor~?)

캠퍼스를 돌아다니며 교수님의 문제를 풀고 잡는 위치 기반 게임형 학습 서비스입니다.

## 프로젝트 소개

캠퍼스 곳곳에 과목별 교수님 캐릭터가 나타나 담당 과목의 문제를 냅니다. 문제를 풀면 교수님을 잡을 기회가 생기고, 잡은 교수님과 문제는 도감에 모입니다. 탐색과 수집의 재미를 통해 학습 동기를 높이고, 과목별 문제 풀이와 복습을 자연스럽게 이어 주는 위치 기반 학습 앱입니다.

## 주요 기능

- 위치 기반 교수님 캐릭터 탐색
- 과목별 문제 풀이와 캐릭터 포획 도전
- 교수님 도감 수집
- 푼 문제를 다시 확인하는 복습

## 기대 효과

탐색과 수집의 재미로 학습에 대한 흥미를 높입니다. 과목별 문제 풀이와 복습을 통해 꾸준한 학습 참여를 유도합니다.
